# APDv1 Skills

Kept skills match the current default workflow:

- `post-deploy-portable-bundle`: build the final portable bundle.
- `post-deploy-image-bundle`: build the explicit image-based final bundle.
- `portable-bundle-audit`: read-only final portable audit.
- `official-flow-deploy`: local-run deployment path.
- `official-deployment-audit`: read-only local-run audit.
- `experience-feedback`: terminal-only validated experience merge.

Older variants are archived in `.codex-backups/`.
